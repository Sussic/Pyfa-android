# G05.1 original-only bounded preflight

This directory adds a new independent original exporter. No predecessor test,
bridge/native file, original source, or protected D02.2 artifact is changed.
It retains reconstructed-source / existing supplemental-dataset limitations.

## Frozen finite plan (review before EOS)

Five separate original-only processes: ordinary, drones, spool, ancillary, linked.
Each process receives the retained original path and read-only existing database.
One serial EOS lane, external timeout 180 seconds, address space 1 GiB. Each writes
an exclusive new receipt path. Preserve stdout/stderr and failed receipts. No
candidate imports, downloads, builds, device work, database copies or simulator
measurements. Expected values execute exact original AST bodies, not calculations
copied from candidate code.

- Ordinary: inherited all-V Vexor mixed capacitor/shield/armor/hull fixture; empty
  and capacitor-only Vexors. Six original state commands cover each repair module
  ONLINE/ACTIVE. Initial ranges: 0–100 km, equal 13.5 km, large-offset adjacent
  doubles (retain duplicate coordinates), tiny positive range, very-large finite
  range. Every observation also probes source optimal/falloff/lock boundaries.
- Drones: all-V Vexor, published Light Shield/Armor/Hull Maintenance Bot I, each
  amount 2 / active 1. Original local quantity 2→3 makes shield active 2; retain
  original undo/redo. Four explicit lock/control combinations and source exact/
  one-metre-beyond gates. Check CPU/PG/slots/bandwidth/bay/active limits and original
  publication/type IDs; do not reuse the overfilled inspector drone fixture.
- Spool: inherited Rodiva / Heavy Mutadaptive Remote Armor Repairer II anchor.
  Original local spool commands: default, explicit zero, CYCLES 3, undo/redo,
  reset. Current module override beats default force=False original options.
- Ancillary: two Vexors each with one Small Ancillary Remote Armor Repairer and
  one Small Ancillary Remote Shield Booster; factorReload false/true respectively.
  Charges Nanite Repair Paste and Cap Booster 25 are verified with original
  isValidCharge and fitting/resource restrictions. Each module unload/reload is
  executed through original commands, with graph ancReload true/false at every
  state. Source shield/armor/hull columns stay separate from curve values.
- Linked: two inherited outgoing Vexors plus unrelated empty Vexor. Reciprocal
  original links, source shield state edit/history, shared profile/Remote Armor
  Repair Systems 5→4→5/history and source deletion. That skill changes capacitor
  need, so unchanged graph rates are an explicit cap-independence witness. Every observation runs LOCAL
  immediately before original getters; compare forward/reverse read orders.
  Original runtime persistence and candidate durable/history/revision/stale-request
  proof belong to the separately owned candidate matrix.

The original TimeCache class is AST-loaded and its prepareRpsData runs unchanged.
Before fit construction, fail-fast wrappers forbid TimeCache generation/data
access, both CycleInfo/CycleSequence.iterCycles methods, Fit capacitor/tank
getters/helpers (including drain generation), and CapSimulator reset/run. Average cycle parameters remain
allowed and are checked positive/finite. Blocked-call attempts are recorded.
Candidate inherited preparation may reset admission state; this exporter claims
its own stronger no-reset boundary only, not a new production restriction.

Original SmoothPointGetter/Distance2RpsGetter, getApplicationPerKey, applyReps,
checkLockRange/checkDroneControlRange, graph normalizer/denormalizer lambdas and
Shield/Armor/Hull RRColumn._getValue execute directly from retained source AST.
Only GraphSettings access, wx command/event plumbing and column GUI bases use
small noncalculating shims. Source graph options are explicit and time is None.
Sampling retains original order and duplicates, with no sorting/deduplication,
and proves at most 201 points per fit. Per-key rates/application and source
columns provide causal zero/nonzero and capacitor-exclusion witnesses.

Separate no-EOS tests execute original adaptive code with synthetic scalar getters
for exact equal, metre underflow, near-equal duplicates, and midpoint overflow.
Distinct nonnegative km endpoints cannot normally create the minimum-subnormal
metre interval after multiplying by 1000; the direct metre test records that source
edge honestly. Large finite real-fit ranges can remain all-zero and avoid midpoint
refinement; the synthetic ramp separately witnesses overflow rather than claiming
an ordinary repair fixture produces it.

Receipts bind every extracted/imported original file, all harness/fixture files,
ordered inputs/commands/requests, current settings and pre/post DB SHA. Original service useGlobalForceReload is set
explicitly from each fixture before construction, commands and LOCAL read, and
actual factorReload equality is asserted; the original service otherwise overwrites
the fit flag. Per-observation source_service_options records this reference-only
configuration. This adds no product settings control. Each source
file must still match the same relative retained candidate upstream file; no
candidate calculation modules are importable. Record roots, module/drone scans,
point counts, elapsed time, peak RSS, zero forbidden/network calls and raw input
preservation. Original fitting legality and meaningful rates must pass before
an original result is accepted. Reviewer/owner clears this exact plan before EOS.
