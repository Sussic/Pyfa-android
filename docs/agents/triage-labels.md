# Triage labels

These mappings apply to GitHub Issues in `Sussic/Pyfa-android`.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for agent work |
| `ready-for-human` | `ready-for-human` | Human action required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a canonical role, use its mapped tracker label.

The existing `bug` and `enhancement` labels remain the category labels.

These labels describe triage state. Task execution and acceptance
continue to follow `../../AGENTS.md`, `../android/STATUS.md`,
the roadmap and the relevant task brief.
