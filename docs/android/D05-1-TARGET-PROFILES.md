# D05.1: reusable named target profiles

## Bounded outcome
Provide the original 195 read-only fitting target profiles and a reusable custom catalogue with create, edit, rename, duplicate and delete. Per-fit selection is a live identity binding: shared edits update every bound fit atomically. No Profile, Anonymous and Named remain distinct. Fit duplication retains the named binding; manual inline edits detach to Anonymous. Deletion explicitly confirms affected fits and atomically clears their selections, with session-local undo/redo.

This is the target-only child of D05. Damage-pattern collections, global defaults, graph-target selection, clipboard interchange, backup and new graph families remain outside this child. Graph-only Ideal Target ID 0 is not a fitting selection.

## Recorded compatibility decisions
- Resistance input supports finite 0–100% inclusive. The original editor's unwired validator permits values above 100% that produce negative damage; Android rejects them rather than clamping or claiming full original-domain equivalence.
- Preserve all eight raw fields and original numeric kinds for server-selected/copied built-ins. Blank speed/radius retain raw null and effective zero; blank signature/HP mean unlimited, while finite zero remains zero.
- Duplicate preserves finite HP, explicitly correcting the original helper's silent HP omission.
- Named-library raw integer tokens are limited to 0 through 2^63−1, matching the existing native parser. Every original built-in integer fits; custom editor saves use floating-point tokens. This representation rule rejects unsupported edited durable integers without rewriting and does not alter existing anonymous C02 inputs or claim arbitrary-integer interchange parity.
- Delete clears bound fits atomically rather than leaving dangling or stale references. Existing anonymous values are not automatically converted into named records.
