incoming-module, profile, history, tank/capacitor/output and capacitor-graph APIs.
Qualify finite ordinary three-fit remote repair, capacitor transfer/neut, nosferatu,

all D02 topologies, mixed incoming families, graphs or Android acceptance.

Original preflight and measurement are source-derived and independently reviewed.
The retained reconstructed source and supplemental dataset still need clean-pin
qualification. No expected output is generated from the implementation under test.

## Product correction

Persist saved-projection edges in their current EOS iteration order. Previously,
_capture sorted the durable list by random logical UUID, so reconstruction could
reverse the desktop insertion order even though the first observed numerical
values matched. Keep public snapshot display sorting and command edges unchanged.
Existing stored lists retain their exact current order without schema migration;
lost historical insertion order cannot be recovered from old sorted records.

RemoteSupportUiTest has one explicitly scheduled remote_support phase method over
existing screens: source open/edit/return, recipient tank/capacitor/outgoing values,
source/link history, nullable range draft recreation, incoming neutralizer and
stale deletion. Airplane mode, denied INTERNET and disposable test data are required.
Compilation alone is not execution, screenshots, usability or release qualification.

## Bounds

One EOS process at a time, 180-second timeout and 1 GiB address space. Module-only
fixtures do not activate incoming drone/fighter admission; diagnostic event bounds
are not a new production guard. Offline Gradle uses one worker, 2 GiB heap,
768 MiB metaspace and 420 seconds in the coordinated build slot. No new downloads,
database copies, device/local execution or release publication.

Exact final proof belongs to the candidate's source freeze, test/review receipts
and archive audit; preliminary retained failures never count as successful gates.
