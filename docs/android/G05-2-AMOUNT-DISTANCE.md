The original amount mixin is copied exactly and reuses the guarded distance application body. Schedules, generation, admission weights, complete-error semantics, finally cleanup and native actual-worker ownership are unchanged. Mode switches invalidate stale results while preserving input drafts and selections; they do not release a still-running worker.
